# US Poker Rooms (web)

Next.js App Router UI over the sourced US live poker rooms dataset. Prefer the
live FastAPI (`us-poker-rooms`); when the API is down, fall back to a **full
offline JSON snapshot** synced from `poker.db` — not a tiny 3-room fixture.
Nothing is invented; coverage gaps stay visible.

Companion repos:

- Database / ingest / API: [`BigWaveDan/us-poker-rooms`](https://github.com/BigWaveDan/us-poker-rooms)
- Android: [`BigWaveDan/us-poker-rooms-android`](https://github.com/BigWaveDan/us-poker-rooms-android)

## What each view does

| Route | Role |
| --- | --- |
| `/` (Home) | **OSM / Leaflet map** of rooms with latitude+longitude (live `GET /rooms?limit=2000`, else offline snapshot). Pin → preview pane → `/rooms/[slug]`. Coverage tiles + stats. |
| `/rooms` | Searchable / filterable directory (live API or full `rooms-snapshot.json`). |
| `/rooms/[slug]` | Detail: address, hours, games, phone, website, coords, **sources**. |
| `/activity` | Placeholder collection feed |
| `/about` | Product notes |
| `/settings` | Preference skeleton + API base URL |

## Run

Start the API from the database repo:

```bash
# in us-poker-rooms
python3 -m venv .venv
.venv/bin/pip install fastapi uvicorn
.venv/bin/uvicorn api:app --host 0.0.0.0 --port 8000
```

Then this app:

```bash
npm install
npm run dev
```

Optional `.env.local`:

```
NEXT_PUBLIC_API_BASE=http://127.0.0.1:8000
```

Default API base is `http://127.0.0.1:8000`.

## Offline snapshots

| File | Contents |
| --- | --- |
| `lib/rooms-snapshot.json` | All rooms (+ sources) for list/detail offline |
| `lib/rooms-geo.json` | Coords-only pin subset (map tooling / lighter asset) |

Regenerated by the shared refresh script (also copies Android `poker.db`):

```bash
cd /path/to/us-poker-rooms
python scripts/refresh_rooms.py
```

Cron example (weekday mornings, machine local time):

```cron
2 8 * * 1-5  cd /path/to/us-poker-rooms && /usr/bin/python3 scripts/refresh_rooms.py >> /tmp/poker-refresh.log 2>&1
```

TopBot / Grok Bot can run the same command via a routine. See
[`SOURCES.md`](https://github.com/BigWaveDan/us-poker-rooms/blob/main/SOURCES.md)
for PokerLog, PokerAtlas, commissions, Bravo, and property-site notes.

## API

`NEXT_PUBLIC_API_BASE` (default `http://127.0.0.1:8000`)

- `GET /health`
- `GET /states`
- `GET /rooms?state=&city=&q=&status=&type=&limit=&offset=`
- `GET /rooms/{slug}` (includes `sources`)
